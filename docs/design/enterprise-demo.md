# 企业AI 智能运维平台定制演示版

## 决策与边界

本分支面向演示与操作手册，交付独立品牌的浏览器沙盘，不替代真实运维系统。当前系统完整后端保留在源码中，但不打包启动，不改 API、Proto 或数据库。入口 App 只挂载 enterprise 页面，原版路由不开放；直接访问原版路径回到运维总览。浏览器会话标记只是进入演示的状态，不是身份认证。

独立品牌名称为企业AI 智能运维平台，英文 Enterprise AI Operations Platform。原创几何 X 标识使用蓝色与青色。默认浅色，支持深色；布局改为顶部业务导航加局部侧栏，首页为总览。布局与样式细则见前端设计规范的企业演示版章节。

## 数据和交互

示例空间为虚构的星澜企业。包含 24 项资源、12 条告警、8 篇知识、3 个流程、6 条初始执行记录。时间以首次生成的快照为锚，刷新保留，恢复示例时重新生成。指标曲线为数学构造的模拟趋势，不反映现场采集。

数据通过类型化本地服务更新，使用 enterprise-ai.sandbox.v1 存储。读取时检查版本与基本记录结构；数据损坏或存储失败时显示警告，继续以内存状态工作。未知版本不自动覆盖，操作员恢复示例或明确修改后才写入。不同浏览器、不同域名及端口的数据相互隔离。用户新建文档内容不自动翻译；初始文档提供中英文，编辑仅更改编辑开始时的语言。

告警支持待处置到处理中或已关闭，已关闭告警不重新打开。关闭告警、执行流程、恢复数据均需确认，取消不产生变更。流程仅产生记录，最多保留 100 次，无远程命令、后台任务或外部模型调用。AI 回答由三个固定场景生成，明确标注模拟结果。

## 开源与交付

使用 AGPL-3.0-only；保留原始版权与商标声明，平台说明明确独立版本身份，并提供对应运行版本的源码归档和第三方许可声明。构建从当前分支发布，不合并到 main。构建版本来自 Git 提交，源码打包只使用 git archive HEAD，不包含工作区凭据和未跟踪文件。

容器使用独立 Compose 项目、只读文件系统、非 root 用户、资源上限与日志轮转。无需数据库；部署与回滚见安装文档。Word 手册及截图为发布产物，源码保留可复现的手册生成脚本与步骤。
